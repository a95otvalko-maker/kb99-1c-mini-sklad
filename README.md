# kb99-1c-mini-sklad
Файл конфигурации информационной базы Мини Склад, включает в себя:
Справочники: Товары, Контрагенты.
Документы: Поступление, Реализация (формы, движения — базовые).
Интерфейс: подсистема «Мини-Склад» с обьектами внутри

# Что бы открыть файл конфигурации необходимо:
1. Запустить 1с в режиме конфигуратор
2. Меню Конфигурация
3. Загрузить конфигурацию из файла
4. Выбрать файл
5. ок
